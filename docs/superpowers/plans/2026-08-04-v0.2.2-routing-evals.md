# v0.2.2 Routing Evals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every active Skill eval machine-readable, cover the known adjacent-Skill routing risks with paired cases, and fail CI when routing metadata or minimum coverage regresses.

**Architecture:** Keep routing evidence inside each self-contained `skills/<skill-id>/evals/evals.json`. Extend the existing repository audit as the deterministic schema and coverage gate; it validates documentation quality but does not claim that a model actually routed correctly. Preserve all Skill trigger contracts and runtime workflows for the later v0.2.3 phase.

**Tech Stack:** Python 3 `unittest`, JSON eval assets, existing `scripts/audit_skills.py`, GitHub Actions.

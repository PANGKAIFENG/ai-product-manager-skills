# Grill-Me Question Patterns

Use these patterns to keep pressure testing focused and interactive.

## Dependency Questions

- If this assumption is false, which part of the plan fails first?
- What has to be true before this step is worth building?
- Which dependency is outside the team's control?

## Failure Mode Questions

- What would make users ignore this?
- What would make this too expensive to operate?
- What breaks when the happy path only works 70% of the time?

## Tradeoff Questions

- What are you explicitly choosing not to optimize?
- Which user segment loses if this succeeds for the target segment?
- What is the cheapest reversible version of this decision?

## Evidence Questions

- What evidence would convince you to stop?
- What evidence would upgrade this from plausible to worth building?
- Which part can be checked from code, logs, PRD, or docs before asking the user?

Ask one question at a time and include your current recommended answer or assumption.

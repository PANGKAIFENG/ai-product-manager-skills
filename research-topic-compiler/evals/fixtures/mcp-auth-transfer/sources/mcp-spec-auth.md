Frozen summary: authorization requirements depend on the transport and deployment boundary. Remote HTTP transports can require standardized authorization flows. Local stdio deployments operate through the local process environment and are not equivalent to a remote resource server.

The specification does not imply that every deployment should use an identical OAuth topology.

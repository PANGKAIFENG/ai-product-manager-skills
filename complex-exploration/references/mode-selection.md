# Complex Exploration Mode Selection

Use this reference after identifying that the task is complex enough to require exploration rather than immediate execution.

| Mode | Use When | Output |
| --- | --- | --- |
| Quick Mode | User asks a complex question but may only need a fast framing. | Task type, hidden assumptions, true question, next step. |
| Deep Mode | Strategy, roadmap, pricing, positioning, or complex PRD exploration needs a formal path. | Exploration definition, framework options, evidence plan, intermediate artifacts. |
| Review Mode | There are multiple discussion rounds, versions, or project artifacts to inspect. | Process review, valuable vs low-value iterations, turning points. |
| Asset Mode | The user wants reusable methods, templates, or collaboration rules after the work. | Cognitive, structural, methodological, tool, and influence assets. |

Do not run every mode by default. Choose the mode that matches the current stage and name the next downstream Skill when the exploration becomes research, PRD drafting, pressure testing, or assetization diagnosis.

# Red Baseline

记录日期：2026-07-29。以下场景在不加载本 Skill 的条件下执行，用于固定已观察到的失败模式。

## Baseline A: DWS 能力不足

基线在 DWS 缺少或失败时擅自改用浏览器操作钉钉表格，破坏了钉钉写入只能通过 DWS 的权限边界。

## Baseline B: 导出与恢复

基线出现了四类数据风险：

- 同名 Sheet 时直接终止，没有使用时间后缀；
- 绕过 Excel 导出，自行调用云效分页或 API；
- 对重复标题或 URL 自动去重；
- 把 `创建者` 改写为 `创建人`。

## Baseline C: 异常迭代

基线把未识别的迭代静默排到末尾，导致用户无法在外部写入前发现数据质量问题。

## Green Gates

- 浏览器只导出云效，DWS 只写钉钉。
- DWS 失败只能增加 `--verbose` 重试一次，不允许工具回退。
- 同名使用 `-HHmm`；重复数据全部保留。
- 未知迭代在创建 Sheet 前阻塞并列出异常。
- 字段严格为 8 列，排除父 ID 和描述。

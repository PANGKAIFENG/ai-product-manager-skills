# Mockup Verification Checklist

Run or document these checks before final handoff:

- The PRD and UI spec used are named.
- Output mode is stated.
- Structure-stage files exist: `ascii-layout.md` and screen/state contract.
- Implementation-oriented runs include `component-map.md` and `implementation-notes.md`.
- Standalone HTML is labeled as visual reference, not production code.
- At least one active/running state and one non-happy-path state are visible when relevant.
- Desktop layout is checked around `1440x900` and `1280x800`.
- Text does not overflow buttons, tabs, rails, cards, panels, or tables.
- Screenshots or verification notes are included.
- Production routes or design files were not overwritten unless explicitly requested.

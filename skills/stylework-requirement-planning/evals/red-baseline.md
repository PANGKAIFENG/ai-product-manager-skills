# Red Baseline

记录日期：2026-07-29。测试在不加载本 Skill 的条件下执行。

## Observed failure

面对只有标题和基础字段的一批需求，基线要求用户先补充描述、提出方、期望时间、价值、依赖等大量信息，并在信息不足时暂缓建议。

这与真实团队录入习惯冲突：批量补全成本太高，也无法先让用户看懂“这一批在解决什么”。

## Green gates

- 先做主题聚类和批次摘要。
- 标记重复、依赖、前置能力和模糊项。
- 最多提出 1-3 个批次级高价值问题。
- 信息不足时仍给临时优先级与迭代建议。
- 每个关键建议都有理由、缺失信息、风险和置信度。
- 全程只读，用户最终手工修改。
